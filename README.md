# 문장에서 전시를 꺼내다

입력 문장과 분위기를 바탕으로 전시 제목과 짧은 설명을 생성하는 반응형 웹페이지입니다.

## 로컬 실행

이 프로젝트는 Vercel 서버리스 함수(`/api/generate`)를 사용합니다. 일반 파일 열기나 정적 서버만으로는 실제 AI 모드가 동작하지 않습니다.

1. Vercel CLI를 설치하고 로그인합니다.
2. 프로젝트 폴더에서 `vercel dev`를 실행합니다.
3. 브라우저에서 표시되는 로컬 주소로 접속합니다.
4. 실제 AI 모드를 사용하려면 아래 환경 변수를 Vercel 프로젝트의 환경 변수 또는 로컬 `.env.local`에 설정합니다.

## GitHub 및 Vercel 배포

1. 이 폴더를 GitHub 저장소에 올립니다. `.env`, `.env.local`, API 키를 커밋하지 마세요.
2. Vercel에서 **Add New → Project**를 선택해 해당 저장소를 연결합니다. 별도 프레임워크 설정 없이 배포할 수 있습니다.
3. Vercel 프로젝트의 **Settings → Environment Variables**에서 아래 값을 등록하고 Production 및 필요한 Preview 환경을 선택합니다.
4. 저장소에 다시 배포합니다. 환경 변수를 바꾼 뒤에도 새 배포가 필요합니다.

| 변수 | 필수 | 설명 |
| --- | --- | --- |
| `OPENAI_API_KEY` | 예 | OpenAI API 키. 브라우저에 전달되지 않고 서버 함수에서만 사용됩니다. |
| `EXHIBITION_ACCESS_CODE` | 예 | 실제 AI 모드에서 사용자에게 알려줄 실습 접속 코드. 길고 추측하기 어려운 값으로 설정합니다. |
| `OPENAI_MODEL` | 아니요 | 사용할 모델 ID. 기본값은 `gpt-4.1-mini`입니다. 계정에서 사용할 수 있는 모델을 지정하세요. |

실습 접속 코드는 웹페이지에 직접 넣지 않습니다. 페이지 사용자는 실제 AI 모드에서 코드를 입력하고, 서버 함수가 Vercel 환경 변수 값과 대조합니다. 입력 문장은 제목과 설명을 만들기 위해 OpenAI API로 전송됩니다. 예제 모드에서는 외부 요청이 발생하지 않습니다.

## 오류 안내

페이지는 누락/오입력 코드, 서버 환경 변수 누락, OpenAI 인증 문제, 사용량 한도, 일시적인 서비스 오류 및 응답 형식 문제를 구분해 다시 시도하거나 운영자 설정을 확인하도록 안내합니다. OpenAI API 사용에는 계정 사용량 및 결제 설정이 필요할 수 있습니다.
